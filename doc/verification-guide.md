> 「复制诊断信息」内容、复现步骤，再反馈。

## 1. Android 手机验收

### 1.1 安装与启用

```sh
./script/install-debug.sh         # 构建 + adb 安装 + 启用并选中 IME
```
1. 打开 JRime → 允许通知权限（部署完成提示用；可拒绝）。
2. 系统设置 → 输入法 → 启用 JRime → 切换为当前输入法。
3. 打开 App 内「测试输入」面板（工具栏键盘图标）。

**期望**：键盘立即出现，顶栏为语义图标 + 值：设置 / 标点值 / 数字 / 剪贴板 / 表情 / 简繁值 / 全半值 / 常用语 / 扩展示例(+) / 中EN / 收起。

### 1.2 打字与手感

- 输入 `nihao` 等双拼：组合态编码在顶栏回显，候选条占数字行，点选上屏。
- 字母键空闲时角标显示韵母键位（q=iu、w=ei、r=uan…），组合时角标变为选词数字。
- 长按/滑动/连发/空格长按滑光标/双空格句号：与旧版行为一致。
- 按键气泡：开启时按下浮出键面字符。
- 按键音/振动：设置里可开系统按键音、调音量、开振动；**自定义音效包已移除**（原 YAML 音效自定义），仅使用系统按键音。

### 1.3 候选

- 候选超过 7 条：右侧出现 `1/N` 与 `›`，翻页后点选应上屏对应全局序号候选。
- 长按候选：菜单（置顶/删词/复制/查编码）出现，不再静默删词。
- 候选注解类型可在设置→输入→注解类型切换（辅码/声调/空白）。

### 1.3.1 长按输入

- 字母行长按：数字/大写/符号（键面角标提示）。
- 数字行长按/上滑：对应符号（`!@#$%…`）。
- **空格长按**：切到「首选语音输入法」（键盘组可开关）；需先安装语音输入法。
  可行性、路线对比与限制见 [voice-input-notes.md](voice-input-notes.md)。
- **回车长按**：插入换行；**逗号长按**：插入中文顿号「、」。
- 关闭「长按空格语音输入」后，空格单击/滑动光标不受影响。

### 1.4 面板与工具栏

- 📋 剪贴板面板：历史/收藏/置顶/编辑/清空；剪贴 chip 一键粘贴。
- ☻ 符号/表情面板：分类、点选上屏。
- 「语」常用语面板：列出随包置顶词；点选上屏并回键盘；可新增（文本+编码）与删除。
- 简/繁、全/半：按钮点亮状态与候选/标点行为一致。
- 中英切换方式（输入组）：Shift 或顶栏按钮 / 仅顶栏按钮 / 仅 Shift；切到「仅顶栏按钮」后单击 Shift 不再翻转模式，顶栏按钮仍可切。

### 1.4.1 用户词典（设置 → 系统与数据 → 管理用户词典）

- 选择词典（默认飞鹤快拼）、搜索词条/编码、查看词条/编码/频次。
- `+1`：调高频次；`删除`：标记删除（负频次，可恢复）；添加：填词条+编码后点「添加」。
- 编辑后引擎会重启，回到键盘重新输入即可生效。
- 注意：删除是「负频次标记」，导出里仍能看到（标为已删除）；词典为空时显示「共 0 条」。

### 1.5 设置中心（首页 → 设置）

分类首页：六个分类卡片（输入 / 键盘 / 候选 / 外观 / 剪贴板 / 系统与数据，带说明与项数）；
点进分类后看具体行，左上「‹ 返回」回分类首页；首页顶部搜索跨全部分类，分类详情内也可局部搜索。

- 输入规则 10 条：简繁字型、全角、英文标点、表情候选、联想、单字优先、全拼显示、码区提示、增广字集、注解类型。切换后立刻影响输入（无会话时不可用显示「—」）。
- 默认值（2026-11-21 调整）：中文标点（英文标点关）、通用字集（增广关）、表情候选开、联想关、注解声调。
- 外观：深浅模式（跟随/亮/暗）、强调色（蓝/绿/紫）、候选单页数量、候选字号、键面提示、候选注解开关。
  注：候选字号/键面提示/候选注解开关此前未注入键盘（写死 18sp），2026-11-21 已修复，现应立即生效。
- 系统与数据：管理用户词典、导出用户数据备份、恢复备份（二次确认）、复制诊断信息、导入字体。
  （此组此前因遗漏动作行不可见，2026-11-21 已修复；若看不到请更新到最新构建。）

### 1.6 数据与稳定性

- 导出备份：选择保存位置 → 生成 zip（常用语 + default.custom + 各用户词典文本）。
- 恢复备份：选 zip → 确认 → 提示恢复词典数，引擎重启后词库生效。
- 启动失败：若引擎异常，主界面弹「输入引擎启动失败」，点重试可恢复（不会静默无响应）。
- 连续使用 3 天：无崩溃/无失焦/无键盘消失。

### 1.7 Android 已知限制

- 设置页滑块范围过大会崩溃的问题已修复（大范围整数改为文本编辑、滑块步数有上限）；如仍遇到请报告。
- 用户词典编辑会重启输入法引擎（短暂中断，属预期）。

- 联想/语法模型：`predict.db`/`gram` 未随包内置，界面开关存在但可能无可感效果。
- 导入字体只影响候选/预编辑，不影响键面字母。
- 候选高亮由引擎决定；当前引擎走 Bulk 全量候选，通常无高亮态。

### 1.8 模型化扩展（P5）

- 顶栏「+」（扩展示例）→ 切到 `sample.symbols` 键盘；点符号上屏；「返回键盘」回内置键盘。
- 开发说明见 [extension-guide.md](extension-guide.md)；示例代码 `extensions/sample/`。
- 扩展动作/键盘/工具栏均为 Kotlin model，冲突在启动注册时直接报错。

### 1.9 本轮重构验收（与 final-acceptance 对应）

- 应用层不再解析 YAML/主题；设置页不再出现旧横屏/分屏/隐藏工具栏等死项；键盘功能键为矢量图标；
  启动图标为方案中立的 J 标记。详见 [final-acceptance.md](final-acceptance.md)。

## 2. macOS 验收

### 2.1 安装与启用

```sh
./script/install-macos-ime.sh      # 构建 .app 并复制到 ~/Library/Input Methods/
```
1. 系统设置 → 键盘 → 输入法 → `+` → 简体中文 → **JRimeIME** 添加。
2. 菜单栏输入法菜单切到 JRimeIME（或 Ctrl+Space）。
3. 在任意文本框输入 `nihao`。

**期望**：出现组合态与候选（系统候选窗）；点选上屏。

### 2.2 中英切换与快捷键

- **单独按一下 Shift**：中文 ↔ 英文切换（再按切回）。
- Shift+字母/方向键等组合不应触发切换；Cmd+C / Ctrl+A 等快捷键必须直通应用。
- CapsLock：按 schema 行为提交编码（`commit_code`）。

### 2.3 macOS 已知限制

- 候选窗是系统 `IMKCandidates`（单列面板）：无自定义主题、定位由系统决定；重复文本候选点击按文本匹配（同名候选可能选错）。
- 桌面进程（`desktop:app`）的候选窗会在无输入时自动隐藏、有输入时出现；设置文件改动约 1.5s 内热重载。
- 修改 YAML/schema 不会自动生效（桌面端暂无部署热更新）；需重新部署/重启引擎（后续批次）。
- 每个宿主应用可能拉起一个引擎 JVM（IMK controller 粒度），内存占用随应用数增加；D3 后续可做 broker。
- 自绘 CMP 候选窗未启用：公开 IMK API 不提供插入点屏幕坐标，需要辅助功能权限；默认系统候选窗。
- 若输入法无反应：`pkill -f JRimeIME` 后重新切换输入法；仍不行可删除
  `~/Library/Input Methods/JRimeIME.app` 回滚到系统输入法。

## 3. Linux 验收（IBus）

前提：Linux 桌面 + `python3-gi` + IBus + JVM。

```sh
# 1) 引擎包（CI 的 jrime-engine-linux-x64.zip 解压；或本地构建）
export JRIME_ENGINE_CLASSPATH=/path/to/engine-classes
export JRIME_RIME_DYLIB=/path/to/librime_jni.so
export JRIME_SHARED_DIR=$HOME/.local/share/jrime/shared
export JRIME_USER_DIR=$HOME/.local/share/jrime/rime

# 2) 安装 IBus 组件
./desktop/linux/install.sh
ibus-daemon -drx
```
3. GNOME 设置 → 键盘 → 输入源 → 添加「JRime 飞鹤快拼」；切换后输入 `nihao`。

**期望**：组合态/候选/上屏；Shift 切中英（`Release+Shift_L` 配对）。
**已知**：候选为 IBus 面板；Shell 尚未在 Linux 会话实测（协议客户端有 6 个单测）。
