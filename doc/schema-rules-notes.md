# 默认方案规则审查（飞鹤快拼 / flypy_xhfast）

> 2026-11-21。用户要求「飞鹤快拼只是移植前的拼音方案，具体规则看看优化下」。本文盘点随包的
> 方案开关与默认值，给出结论与后续动作。**默认方案不等于产品身份**，见 `doc/style-guide.md`。

## 1. 当前开关与默认值（`flypy_xhfast.schema.yaml` + `.custom.yaml`）

| 开关 | 状态 | 默认 | 评价 |
|---|---|---|---|
| `ascii_mode` | 中 / En | 中 | 正确 |
| `ascii_punct` | 。/ . | **英文标点（reset: 1）** | ⚠️ 对中文输入法而言反直觉；建议默认中文标点。改动需同步预编译 build 并重新部署，列入规则批次 |
| `full_shape` | 半 / 全 | 半 | 正确 |
| 字型（zh_simp/zh_trad/zh_hk/zh_tw） | — | 简体（App 启动时显式设 zh_simp） | 正确 |
| `emoji` | 🈚️ / 😄 | 开 | 符合主流 |
| `prediction` | 休想 / 联想 | 关 | 省资源，合理；可在设置开 |
| `char_mode` | 词组优先 / 单字优先 | 词组优先 | 合理 |
| `charset` | 通用 / 增广 | **增广（reset: 1）** | 生僻字更全但候选更长；可考虑默认通用、按需开 |
| `charset_hint` | 码区隐藏 / 显示 | 隐藏 | 合理 |
| `preedit_format` | 双拼 / 全拼显示 | 双拼 | 合理 |
| 注解类型（mask/tone/comment_off） | 辅码/声调/空白 | **声调** | 合理（可切辅码） |
| 候选单页 `menu/page_size` | 方案补丁 9 / 全局 7 / App 默认 7 | 9（方案补丁优先） | App 分页使用自身偏好 7，存在「引擎 9 / 界面 7」的双事实；建议统一到 7 或把 App 默认改 9 |
| 候选键 `alternative_select_labels` | 1–9,0 | 数字行 | 与键盘候选条一致 |

## 2. 长按/手势规则（App 层，已定）

- 字母行：长按数字（Q 行）/大写（A、Z 行）/符号；滑动标点/光标/音节。
- 功能行新增：空格长按→语音输入法、回车长按→换行、逗号长按→顿号；句号长按→问号（既有）。
- 面板/菜单位于顶栏，不再占用键面手势（保持 2026-11-19 的「键面只做输入」决定）。

## 3. 结论与建议（按优先级）

1. **统一候选单页数量**：App 默认 7，方案补丁 9。建议方案补丁改 7（与候选条宽度/设计一致），
   或 App 默认改 9 后同步设计检查。→ 需要预编译 + 真机回归，列下一批次。
2. **标点默认中文**：`ascii_punct reset: 0`（或删除 reset），同步 shared + `assets/rime/build`，
   并通过部署/升级路径让旧用户生效（需评估重置成本）。→ 下一批次。
3. **charset 默认策略**：默认「通用字集」，设置里明示「增广字集」可开；减少长候选与生僻字干扰。
   → 下一批次，随规则回归一起验证。
4. 其余开关保持现状；联想保持默认关，避免无模型数据的无效联想。

> 本轮不改 schema（涉及预编译产物与旧安装部署链，需要专门的规则批次 + 真机回归）；
> 先把「产品口径与默认值意图」定稿在本文与 `style-guide.md`，同时 App 层的长按/切换/外观规则已先优化。
