# JRime 风格定调（品牌 / 文案 / 视觉）

> 2026-11-21。原则：**JRime 是主体，飞鹤快拼（小鹤双拼）只是当前的默认方案**，不是产品身份；
> 面向「专注、干净、可长期使用的 Rime 输入法」，不沿用上游同文/Trime 的社区身份与文案。

## 1. 命名与身份

| 项 | 用法 |
|---|---|
| 产品名 | **JRime**（大小写固定；中文可写「JRime 输入法」） |
| 输入法子类型名 | `JRime 输入法` / `JRime input method`（不再用 slogan 当子类型标签） |
| 默认方案 | 「小鹤双拼 / 飞鹤快拼（flypy_xhfast）」——在说明里表述为**默认方案**，明确其他 Rime 方案可导入切换 |
| 上游 | 只在「开源说明 / 关于 / README 致谢」里出现 Trime、Rime、OpenCC，且用中立表述；具体社区群组、上游社交账号不在应用内展示 |
| 禁止 | 应用界面上出现「同文输入法」「Trime」作为产品名；不再贴上游 QQ/Telegram 入口 |

## 2. 文案语气

- 简洁、直接、动词开头：设置项标题用名词短语（「候选单页数量」），说明用一句话讲清影响。
- 中文用简体为主，繁体 locale 保持对应写法；英文文案不堆术语。
- 面向「日常输入」：强调手感、候选、词库、稳定，不承诺输入法的识别率/云能力。
- 错误/限制如实说明（如「需先安装语音输入法」「切换输入法可能丢失未上屏编码」）。

## 3. 视觉

- 品牌色沿用键盘强调色默认值：**蓝色**（浅色 `#1A73E8` 系、深色 `#8AB4F8` 系），绿/紫为可选 accent。
- 形状：键盘键圆角、面板/卡片与键面同一套 shape token；设置页分类卡片用 Material3 Card + 16dp 内边距。
- 图标：工具栏用单色字符/emoji 现有约定（⚙ / . , / 123 / 📋 / ☻ / 简繁 / 全半 / 语 / 中EN / 收起），
  不引入第二套图标体系。
- 深浅模式只有一个概念：外观组「深浅模式」同时驱动应用主题与键盘（旧 `ui_mode` 已移除）。
- 动效克制：键面按压气泡、候选切换、面板切换沿用现有 Compose 动画；不加装饰性动画。

## 4. 规则与默认值（产品层）

- **默认方案**：flypy_xhfast；简繁默认简体；emoji 候选默认开；联想默认关（按需开）；注音默认声调注解。
- **标点**：默认中文标点（`ascii_punct reset: 0` 已落地）；需要英文标点用工具栏「. ,」或输入规则切换。
- **字集**：默认通用字集；需要生僻字在输入规则开「增广字集」。
- **长按**：字母行→数字/大写/符号；空格→语音输入法；回车→换行；逗号→顿号；句号→问号（既有）。
- **中英切换**：默认「Shift 或顶栏按钮」，可在输入组改为仅按钮/仅 Shift。
- **候选**：单页默认 7（与键盘宽度/候选条匹配），可在外观组调 5–9。
