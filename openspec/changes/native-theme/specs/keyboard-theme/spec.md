# Spec Delta

## Purpose

输入法键盘外观与布局的唯一来源是应用内置的原生主题：无运行时主题解析与切换，
视觉对标 Gboard，亮暗跟随系统，辅助码按键在默认布局上一键可达。

## ADDED Requirements

### Requirement: 布局与外观由代码定义

键盘布局（按键集合、行列排布、每键的全部行为槽位）与视觉参数（配色、圆角、
间距、字号）是应用代码的一部分；安装后的设备上不存在任何可被修改的主题
数据源，APK 内不携带主题描述文件。

#### Scenario: 全新安装直接呈现内置主题

- **WHEN** 全新安装并启用输入法
- **THEN** 键盘直接以内置 Gboard 风格呈现，全程无主题解析步骤，用户目录与
  APK 内均无主题文件被读取或释放

#### Scenario: 不存在主题切换入口

- **WHEN** 用户浏览应用设置与键盘内菜单
- **THEN** 不存在主题选择、配色选择或主题导入的任何入口

### Requirement: Gboard 风格视觉

键盘呈现 Material Design 语言：圆角按键、按键间留缝、功能行与字母键的
明度分层、候选条与键盘一体的平面风格；具体色值与圆角在实施时对照 Gboard
实机截图校准，并以模拟器截图交主人验收。

#### Scenario: 亮色环境呈现亮色键盘

- **WHEN** 系统处于日间模式
- **THEN** 键盘呈现浅色背景 + 深色文字的亮色配色

#### Scenario: 暗色环境呈现暗色键盘

- **WHEN** 系统处于夜间模式
- **THEN** 键盘自动切换为深色背景 + 浅色文字的暗色配色，无需任何手动操作

### Requirement: 辅助码按键可达

默认键盘底行有一个发送 `/` 的独立按键；在输入组合中按它即进入辅助码/
声调过滤输入（`/` 后接辅助码字母或大写声调字母），无需长按或翻页。

#### Scenario: 辅助码一键过滤单字

- **WHEN** 已输入双拼（如 `ni`）后按该按键，再输入辅助码字母（如 `h`）
- **THEN** 候选按辅助码过滤（等价于直接追加辅助码的既有行为）

#### Scenario: 声调过滤一键可达

- **WHEN** 已输入双拼后按该按键，再输入大写字母（如 `A`）
- **THEN** 候选按既有声调过滤规则过滤

### Requirement: 输入延迟不劣化

IME 窗口为延迟敏感面；渲染层无论采用何种技术，输入响应必须以实测口径
对照验收：窗口显示到可交互、按键按下到视觉反馈两个口径在替换前后各
实测一轮并归档，劣化程度由主人验收判定。

#### Scenario: 延迟实测归档与验收

- **WHEN** 阶段 1 完成打字环路换血后
- **THEN** 上述两个口径的替换前后实测数字归档进实施记录，且主人对
  实际手感给出放行或迭代意见

### Requirement: 行为面与现行键盘等价

原生布局携带现行默认键盘与符号键盘的全部行为槽位（单击、长按、滑动手势、
键内提示）与既有功能入口（符号页、数字页、编辑键、表情/剪贴板等面板），
替换后用户可达功能不减少；唯一例外是移除已无意义的方案切换入口。

#### Scenario: 打字回归不变

- **WHEN** 在新键盘上执行既有回归项（出字/简拼/单字辅助码/反查/英文内嵌）
- **THEN** 各项行为与替换前一致

#### Scenario: 功能入口保留

- **WHEN** 使用符号页、数字页、编辑键盘与表情/剪贴板入口
- **THEN** 均可正常打开与使用
