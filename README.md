# JRime

**JRime is a focused Rime input method for Android** — a shared Compose keyboard, a compact
settings hub, user-dictionary tools and companion desktop builds. It derives from
[Trime](https://github.com/osfans/trime) and runs the [RIME](https://rime.im/) engine (`librime`)
via JNI.

The default schema is **小鹤双拼 / 飞鹤快拼** (`flypy_xhfast`); that is a default, not a
restriction — JRime is a general Rime frontend and other schemas can be imported and switched like
in any Rime app.

## Features

- **Shared Compose surface**: keyboard, top bar, candidate strip, panels and settings are one
  Compose UI that also targets desktop (KMP), with a single design-token/palette layer.
- **Candidates done for daily use**: paged candidates, long-press menu (pin/delete/copy/query
  code), key-face rhyme hints for 小鹤, configurable candidate page size/size/comments.
- **Input rules in the app**: simplified/traditional, full shape, English punctuation, emoji
  candidates, prediction, single-char priority, full-pinyin preedit, code hints, extended charset.
- **Categorized settings** with search: six groups (input / keyboard / candidates / appearance /
  clipboard / system) instead of one long scroll.
- **Dictionary tools**: browse/search/add/adjust/delete words in user dictionaries; phrase panel
  backed by `custom_phrase.txt`; whole-user-data backup/restore; copy diagnostics.
- **Long-press input**: digits/uppercase/symbols on letters, plus space → voice input method,
  enter → newline, comma → Chinese enumeration comma.
- **Desktop companions** (in progress): a JVM engine/protocol shared by a Compose candidate-window
  app and a settings app; a macOS IMK shell; a Linux IBus engine shell; a Windows TSF scaffold.
- **Stability work**: startup-failure recovery, crash fixes in settings, no-orphan settings tests,
  surface guard tests, golden engine traces.

## Requirements

- Android 8.0 (API 26) or newer.
- Build: JDK 20, Android SDK 37, Gradle wrapper (`./gradlew`). Native engine sources are vendored;
  desktop builds additionally need the host librime build (`harness/README.md`).
- Optional voice input: install any system voice input method (e.g. Google voice typing) to use
  long-press space.

## Build and install

```sh
# Full gate (unit tests + assembleDebug + spotless)
./gradlew test :core:model:jvmTest :core:engine:jvmTest :ui:ime:desktopTest \
  :app:assembleDebug spotlessCheck

# Build + install on a connected device and activate the IME
./script/install-debug.sh
```

Release builds are unsigned by default; provide `SIGNING_KEY`, `KEY_STORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD` (see `app/build.gradle.kts`) to sign.

## Privacy

JRime runs the Rime engine on-device and does not collect or upload typing data. Optional voice
input is handled by whichever system voice input method you switch to (JRime itself requests no
microphone permission). See [PRIVACY.md](PRIVACY.md).
